# GitHub Setup — Broadigyy/Cobblemon-Companion

Repository:

```text
https://github.com/Broadigyy/Cobblemon-Companion.git
```

## Using GitHub Desktop

1. Extract the GitHub-ready ZIP.
2. Open GitHub Desktop.
3. Choose **File → Add Local Repository**.
4. Select the extracted `Cobblemon-Companion` folder.
5. If GitHub Desktop says it is not yet a Git repository, choose the option to create one there.
6. Make the first commit with a message such as:

```text
Initial public release of Cobblemon Companion v1.7.1
```

7. Publish/push to:

```text
Broadigyy/Cobblemon-Companion
```

If GitHub Desktop instead creates a new remote, cancel that step—the remote repository already exists.

## First Release

Once the files appear on GitHub:

1. Open the repository in your browser.
2. Click **Releases**.
3. Click **Draft a new release**.
4. Create tag:

```text
v1.7.1
```

5. Release title:

```text
Cobblemon Companion v1.7.1 — Public Tester Release
```

6. Copy the text from:

```text
docs/RELEASE_NOTES_V1.7.1.md
```

7. Drag your compiled tester ZIP into the release attachments area.
8. Mark it as a **pre-release** while public testing is still underway.
9. Publish the release.

Do not upload private API keys, passwords, tokens, browser cookies, or personal Minecraft/account files.
