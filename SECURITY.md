# Security Policy

If you discover a security or privacy issue, please avoid posting sensitive exploit details publicly before the maintainer has had a reasonable opportunity to investigate.

Open a GitHub Issue with minimal necessary detail and clearly label it as a security concern. If private contact information is added to the project later, this document will be updated with a private disclosure channel.

Only download compiled Cobblemon Companion releases from the official Broadigyy/Cobblemon-Companion repository.
