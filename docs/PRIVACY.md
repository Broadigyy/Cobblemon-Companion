# Privacy

Cobblemon Companion is primarily a local desktop application.

## Local data

Companion stores its profile, cached data, settings, and crash logs under the user's application-data directory, normally:

```text
%APPDATA%\Cobblemon Companion
```

## Minecraft / Cobblemon files

Companion may read data from a user-selected Cobblemon JAR/modpack in order to build its Pokédex, spawn information, item database, and related features.

It does not intentionally modify the selected Cobblemon JAR or Minecraft modpack.

## Network access

Some features may access public third-party services to retrieve missing reference information or Pokémon sprites.

The project does not operate its own user-account system, advertising network, telemetry backend, or analytics service.

## Payments

The in-app "Buy Us a Coffee" button opens the Broadigy Ko-fi page in the user's normal browser.

Companion does not collect or process payment information.
