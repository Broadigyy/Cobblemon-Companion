# Troubleshooting

## Companion will not start

Check:

```text
%APPDATA%\Cobblemon Companion\crash.log
```

Attach that file to a GitHub Issue.

## Data is missing

Open Settings and confirm Companion is pointed at the correct Cobblemon JAR for the modpack you are currently using.

## Overlay is behind Minecraft

Use windowed or borderless fullscreen. Exclusive fullscreen can cover ordinary Windows desktop overlays.

## Spawn information seems incorrect

Spawn data can vary by Cobblemon version and modpack addons. Include the exact Cobblemon/modpack version in your bug report.
