# Cobblemon Companion v1.7.1 — Public Tester Release

Welcome to the first public testing release of Cobblemon Companion.

## Highlights

- Full desktop Cobblemon Pokédex
- Spawn Finder and Poké Snack recommendations
- Weekly Bingo tracker
- Hunt Planner 2.0
- Collection 2.0
- Competitive Team Builder
- Threat Analyzer and Team Advisor
- Breeding Planner
- Move / Ability / Item database
- Crafting and cooking recipe views
- Current Hunt overlay
- Weekly Bingo overlay
- Polished grouped sidebar navigation

## Tester focus

Please report:

- crashes;
- missing Pokémon/forms/items/moves;
- incorrect spawn information;
- display/layout issues;
- overlay issues;
- slow or unresponsive pages;
- modpack compatibility problems.

Use GitHub Issues and include your Cobblemon version and modpack where possible.

## Windows notice

This early build is currently unsigned, so Windows SmartScreen may display an Unknown Publisher warning.

Only download Cobblemon Companion from the official GitHub repository.
