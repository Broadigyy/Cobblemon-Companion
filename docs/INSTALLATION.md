# Installation

## Windows release

1. Download the latest Windows ZIP from GitHub Releases.
2. Extract the ZIP to a normal folder.
3. Run `Cobblemon Companion.exe`.
4. Open Settings and select / auto-detect your Cobblemon installation if required.

Python is not required for the compiled release.

## Windows SmartScreen

Public test builds may currently be unsigned.

Windows can therefore show an **Unknown publisher** or SmartScreen warning. Code signing is planned when financially practical.

Only download official releases from this repository.

## Updating

Close Companion, replace the old application with the newer official release, and start it again.

User profiles and caches are stored separately under `%APPDATA%\Cobblemon Companion`, so normal application updates should not erase progress.
