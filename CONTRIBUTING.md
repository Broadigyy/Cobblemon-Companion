# Contributing

Thanks for helping test Cobblemon Companion.

## Bug reports

Please open a GitHub Issue and include:

- Cobblemon Companion version
- Minecraft version
- Cobblemon version
- modpack name, if relevant
- steps to reproduce the problem
- expected behavior
- actual behavior
- screenshots where useful
- crash log where available

## Feature requests

Feature requests are welcome through GitHub Issues. Please explain the gameplay problem the feature would solve, not only the feature itself.

## Code contributions

Please open an Issue before investing significant time in a code change.
